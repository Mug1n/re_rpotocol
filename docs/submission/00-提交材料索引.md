## 三、验收入口

在解压后的仓库根目录运行：

```powershell
python -m pip install -r requirements.txt
python -B scripts\reproduce_iscx_evaluation.py verify
python -B scripts\verify_acceptance.py reports\acceptance\2026-09-11-abc\acceptance.json
```

预期分别出现 `ISCX evidence: PASS` 与 `acceptance: PASS`。完整 183 项测试命令见 `docs/submission/05-测试分析报告.md`。

## 四、证据边界

- 课程未提供指定 DAT；项目使用两个来源明确的真实 `.dat`、21 个公共样例、18 个自采回环 HTTP 抓包和 ISCX VPN 2016 外部数据进行分层验证。
- ISCX 原始归档约 2.3 GB，不进入提交包；其来源、大小和 SHA-256 已记录，可由复跑脚本核验。
- `third_party/Wireshark/` 是本机安装目录，不进入 Git 或提交 ZIP。其他电脑需要自行安装可信的 Wireshark。
- 所有输出中的“候选”“partial”“empty”均是证据强度状态，不应改写成已识别协议或已恢复明文。
