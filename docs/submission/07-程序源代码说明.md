# 程序源代码说明

## 1. 源代码交付范围

程序源代码随提交 ZIP 中的 `re_rpotocol/` 完整提供。打包基于 Git 已追踪文件，不包含 `.git/`、虚拟环境、缓存、`tmp/` 或本机 Wireshark 二进制。根目录 `PACKAGE-MANIFEST.json` 记录实际提交 commit、文件数量、长度与 SHA-256。

| 路径 | 内容 |
|---|---|
| `experiments/M01/` 至 `experiments/M12/` | 十二个分析模块的实现、README 和单元测试 |
| `experiments/tests/` | 跨模块、真实数据、冻结验收和公共样例测试 |
| `scripts/analyze.py` | profile 驱动的统一分析入口 |
| `scripts/verify_acceptance.py` | 独立验收门禁 |
| `scripts/reproduce_iscx_evaluation.py` | ISCX 证据核验和完整复跑入口 |
| `scripts/*acceptance*` | 本地服务、采集、组装和完整清单工具 |
| `scripts/evaluate_public_samples.py` | 公共样例批量评估 |
| `profiles/` | 便携、正式验收等运行配置 |
| `research/*.schema.json`、`research/M*/` | 数据契约与模块研究说明 |
| `data/fixtures/` | 小型确定性测试数据 |
| `data/external/` | 外部数据来源、许可、哈希和可提交的小型样例 |
| `data/acceptance/` | 冻结回环抓包、独立 truth 和验收中间产物 |
| `reports/` | 公共样例与正式 ABC 结果 |
| `docs/` | 架构、接口、交接、演示与提交报告 |

## 2. 主入口

推荐入口：

```powershell
python -B scripts\analyze.py --input <file> --profile <profile.json> --output-dir <new-dir>
```

模块级入口统一位于 `experiments/Mxx/run.py`。分类额外提供 `build_rows.py`、`prepare_rows.py`、`predict.py` 和 `evaluate.py`。所有 CLI 都可以使用 `--help` 查看参数。

## 3. 源代码约定

- Python 源码使用 UTF-8、类型标注和确定性排序。
- 主 JSON 由严格 Schema 校验，未知顶层字段通常被拒绝。
- 输出目录不可覆盖；复杂产物通过 staging 目录原子发布。
- 上游文件按精确字节计算 SHA-256，消费者不信任路径或文字状态。
- 临时结果写入 `tmp/`；本地依赖写入 `.venv/` 或 `third_party/`，均不提交。
- 测试使用标准库 `unittest`，无需 pytest。

## 4. 第三方组件

| 组件 | 用途 | 是否随源码包提供 |
|---|---|---|
| Python | 运行环境 | 否 |
| jsonschema | JSON Schema 校验 | 否，通过 pip 安装 |
| scikit-learn | RandomForest/分组评估 | 否，通过 pip 安装 |
| joblib | 模型持久化 | 否，通过 pip 安装 |
| Wireshark/TShark/Capinfos | 抓包解析 | 否，用户自行安装 |
| 外部样例 | 测试/验证 | 仅提交许可允许且体积可控部分；来源与哈希随附 |

本项目没有把第三方二进制伪装成自研代码。标准协议解析复用 TShark；artifact 契约、分帧/聚类/对齐/字段基线、恢复限制、行为特征、分类适配、统一编排和独立验收为本项目实现。

## 5. 完整性验证

```powershell
# 语法检查
python -m compileall -q experiments scripts

# ISCX 证据
python -B scripts\reproduce_iscx_evaluation.py verify

# 正式 ABC 验收
python -B scripts\verify_acceptance.py reports\acceptance\2026-09-11-abc\acceptance.json
```

完整 183 项自动化测试见 `docs/submission/05-测试分析报告.md`。如果任何源文件发生变化，旧 `PACKAGE-MANIFEST.json` 的哈希将不再匹配，应重新提交并打包。
