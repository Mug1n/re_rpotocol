# 程序编译和安装使用文档

## 1. 软件说明

本项目为 Python 命令行程序，无需传统 C/C++ 编译。安装依赖后即可运行；“编译检查”使用 Python `py_compile` 验证源文件语法。推荐 Windows PowerShell，路径示例均从解压后的 `re_rpotocol` 根目录执行。

## 2. 环境要求

- Windows 10/11 或兼容的 Linux/macOS。
- Python 3.11 及以上；验收环境为 Python 3.13.9。
- 约 100 MB 可用空间用于源码、数据与普通输出；大型抓包复跑需额外空间。
- 新鲜解析 PCAP/PCAPNG 时需要 Wireshark/TShark；只运行便携 profile 和冻结验收时可不安装。
- 实时接口采集需要 Npcap；读取保存抓包不需要。

## 3. 解压和依赖安装

```powershell
Expand-Archive .\re_rpotocol-submission.zip -DestinationPath .\submission-unpacked
Set-Location .\submission-unpacked\re_rpotocol
python --version
python -m pip install -r requirements.txt
```

依赖包括 `jsonschema`、`joblib` 和固定版本 `scikit-learn==1.7.2`。建议使用虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

`.venv/` 已被 Git 忽略，不能放入提交包。

## 4. 可选安装 Wireshark

从 Wireshark 官方安装包安装，并确认：

```powershell
& 'C:\Program Files\Wireshark\tshark.exe' --version
& 'C:\Program Files\Wireshark\capinfos.exe' --version
```

若使用项目目录下的本地安装，可设置：

```powershell
$env:WIRESHARK_HOME = "$PWD\third_party\Wireshark"
```

`third_party/Wireshark/` 不随 ZIP 分发，另一台电脑必须自行安装可信副本。只有需要现场抓包时才安装 Npcap，并应在演示前测试接口权限。

## 5. 编译/语法检查

```powershell
python -m compileall -q experiments scripts
if ($LASTEXITCODE -ne 0) { throw 'Python syntax check failed' }
```

生成的 `__pycache__/` 不属于交付物，可直接删除或保留在本地；它已被忽略。

## 6. 最小运行

便携 profile 不需要网络、TShark 或 API key：

```powershell
python -B scripts\analyze.py `
  --input data\fixtures\m01-raw.dat `
  --profile profiles\portable.json `
  --output-dir tmp\portable-run
```

输出目录必须不存在。成功后查看：

- `tmp/portable-run/run_manifest.json`：环境、阶段和 artifact 总表；
- `tmp/portable-run/m12/report.md`：确定性证据报告；
- 各阶段目录：结构化 JSON 和二进制 artifact。

再次运行相同命令前应换一个新输出目录；程序拒绝覆盖是设计行为。

## 7. 正式冻结样例与验收

```powershell
python -B scripts\analyze.py `
  --input data\acceptance\frozen-20260910\captures\download-01.pcapng `
  --profile profiles\acceptance.json `
  --output-dir tmp\acceptance-replay

python -B scripts\verify_acceptance.py `
  reports\acceptance\2026-09-11-abc\acceptance.json
```

第二条命令预期输出 `acceptance: PASS`。`profiles/acceptance.json` 通过哈希重新校验冻结的 M01/M07/M11 产物，保证无 TShark 主机也能离线复核；具备 TShark 时可使用不含复用项的 profile 或逐模块新鲜解析。

## 8. 单模块使用示例

```powershell
# 原始输入识别
python -B experiments\M01\run.py input.dat --output-dir tmp\m01

# 抓包识别（显式工具路径）
python -B experiments\M01\run.py input.pcapng --output-dir tmp\m01-pcap `
  --tshark 'C:\Program Files\Wireshark\tshark.exe' `
  --capinfos 'C:\Program Files\Wireshark\capinfos.exe'

# 字节特征
python -B experiments\M02\run.py input.dat --output-dir tmp\m02

# 固定长度分帧 -> 聚类 -> 对齐 -> 字段候选
python -B experiments\M03\run.py input.dat --output-dir tmp\m03 --rule fixed --frame-size 16
python -B experiments\M04\run.py tmp\m03\framing.json --output-dir tmp\m04
python -B experiments\M05\run.py tmp\m04\clusters.json --output-dir tmp\m05
python -B experiments\M06\run.py tmp\m05\alignments.json --output-dir tmp\m06
```

各模块完整参数请执行 `python experiments\Mxx\run.py --help` 并阅读对应 `experiments/Mxx/README.md`。

## 9. ISCX 外部评测复核

无需原始大包即可检查提交证据：

```powershell
python -B scripts\reproduce_iscx_evaluation.py verify
```

如已取得 manifest 对应的原始抓包：

```powershell
python -B scripts\reproduce_iscx_evaluation.py prepare `
  --raw-root <解压后的PCAP根目录> `
  --work-root tmp\iscx-reproduction `
  --tshark <tshark.exe> --capinfos <capinfos.exe>

python -B scripts\reproduce_iscx_evaluation.py train `
  --work-root tmp\iscx-reproduction `
  --run-root tmp\iscx-runs `
  --output tmp\iscx-evaluation.json
```

脚本不会联网下载，不会覆盖已有目录，并会先核对源抓包大小和 SHA-256。

## 10. 可选模型解释

默认分析不会访问外部服务。只有获得授权后才设置临时环境变量并显式调用：

```powershell
$env:DEEPSEEK_API_KEY = '<仅在当前进程设置>'
python -B scripts\analyze.py --input <input> --profile <profile> `
  --output-dir <new-output> --invoke-model
Remove-Item Env:DEEPSEEK_API_KEY
```

调用可能产生网络传输或费用。不得把 key 写入 profile、命令脚本、日志或仓库。

## 11. 常见故障

| 现象 | 原因与处理 |
|---|---|
| `output directory already exists` | 换用新目录；不要删除旧证据后冒充同一轮运行 |
| `tshark unavailable` | 安装 Wireshark，使用 `--tshark` 或设置 `WIRESHARK_HOME` |
| `dependency_unavailable` | 在当前 Python 环境重新安装 `requirements.txt` |
| `hash mismatch` | 输入/上游 artifact 已变化；恢复冻结文件或重新生成完整下游链 |
| M03 `partial` / M06 `empty` | 当前输入或规则证据不足，不是程序崩溃；检查报告限制 |
| 实时抓包无接口/权限 | 安装 Npcap，以管理员权限测试；保存抓包分析不受影响 |

## 12. 提交包校验

根目录 `PACKAGE-MANIFEST.json` 记录打包 commit 和每个文件 SHA-256。抽查文件可运行：

```powershell
$manifest = Get-Content .\PACKAGE-MANIFEST.json -Raw | ConvertFrom-Json
$manifest.commit
$manifest.file_count
```

随后运行 ISCX verify、正式 acceptance verifier 和完整测试。三者均通过后再用于演示或提交。
