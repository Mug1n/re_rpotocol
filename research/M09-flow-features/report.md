# M9 流量统计特征

状态：已调研。检索日期：2026-09-07；仅资料比较，未安装或测试。

用途：利用包级元数据生成流级和方向级统计，供行为分析与分类使用。

| 候选 | 主要特点与优势 | 输入输出及前置条件 | 限制 | 来源 |
|---|---|---|---|---|
| CICFlowMeter | 双向流特征提取，提供包长、时间间隔、方向等统计并导出 CSV | 支持的抓包 → flow 特征；依赖包头、时间与流分组信息，官方项目为 Java 实现 | 不接收任意裸 DAT；方向/超时口径影响结果；依赖和版本兼容性未验证 | [UNB 应用说明](https://www.unb.ca/cic/research/applications.html)、[官方仓库](https://github.com/ahlashkari/CICFlowMeter) |
| 轻量统计方案（标准库/NumPy） | 按课程需求选择少量特征，定义透明，可逐项标记缺失 | M1 导出的包时间、长度、端点和流标识 → 汇总字典 | 流划分、方向、重传处理及突发定义需自行开发，不是标准库现成流分析器 | [statistics](https://docs.python.org/3/library/statistics.html)、[TShark 字段导出](https://www.wireshark.org/docs/man-pages/tshark.html) |

初步建议：采用轻量统计方案，CICFlowMeter 作为需要兼容公开数据集特征时的备选。拟定义包数、各方向字节数、包长均值/分位数、持续时间、包间隔及方向切换；突发按可配置静默间隔划分。长度需注明链路帧长、捕获长度还是 payload 长度，不能混用。

| 特征 | 必要信息 | 缺失时的处理 |
|---|---|---|
| 包长分布、包数 | 可靠包边界及长度口径 | 裸字节流只能做 M2；M3 消息长度不能冒充网络包长 |
| 上下行比例 | 端点与观察视角/角色 | 不知道客户端时写 A→B/B→A，不能把首包方向必然叫上传 |
| IAT、持续时间、速率 | 时间戳、时间单位及流分组 | 单包无间隔；零持续时间不计算速率；无时间戳输出不可计算 |
| 突发、活跃/空闲 | 连续时间序列与阈值 | 阈值属于分析配置，不能默认为标准真值 |

待核实：真实数据是否保留这些元数据。抓包缺失、重传及流超时会改变特征；按线上包统计还是按去重 payload 统计须提前选择，不能将两个定义的 CSV 直接用于同一模型。
