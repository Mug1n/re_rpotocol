# 分析链路架构

当前状态：待 M1-M12 选型完成后收敛。

预期主链路：

`DAT 输入 -> M1 内容探测 -> [确认抓包: M7 标准协议分流] / [裸字节或未知容器: M2 -> M3-M6] -> M8 数据恢复 -> M9-M11 行为分析 -> M12 证据约束解释与报告`

## 设计约束

- 标准协议识别先于未知协议逆向分流。
- `.dat` 是常规扩展名，但格式结论必须来自内容 magic、结构校验和工具严格打开结果。
- 未命中已知抓包容器时按连续原始字节处理，不补造 packet、flow、方向和时间。
- 高熵仅作为压缩、加密或随机性的候选信号。
- 原始抓包、Flow、Stream、Message、Field 必须分层建模。
- 所有字节范围使用零起点半开区间 `[start,end)`。
- 缺失时间、方向或网络元数据时显式返回缺失值，不推造信息。
- 每项推断通过 evidence ID 追溯到输入、日志、参数和观察值。
